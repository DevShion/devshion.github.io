プライバシーポリシー / Privacy Policy

日本語 / Japanese

SHION INDUSTRIESおよびGuitar Traders（以下、「開発者」といいます。）は、本拡張機能「GTcrx」（以下、「本拡張機能」といいます。）におけるユーザー情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 個人情報の収集と管理

本拡張機能は、ユーザーの個人情報や機密情報（ログインID、パスワード、氏名、メールアドレス、クレジットカード情報など）を収集し、開発者のサーバーを含む外部のサーバーに送信・蓄積することは一切ありません。

2. ローカルデータの保存

本拡張機能の設定情報（DeepL APIキーなど）や、コピーされた一時的な商品データは、ブラウザのローカルストレージ（chrome.storage.local）にのみ保存されます。これらのデータはユーザーのローカルデバイス上でのみ管理され、開発者を含む第三者に送信または共有されることはありません。

3. サードパーティサービス（DeepL API）の利用

本拡張機能の自動翻訳機能（Gbase出品用）を利用する場合、ユーザー自身が設定したAPIキーを使用して、翻訳対象のテキストデータが直接 DeepL のサーバーに送信されます。開発者がこのデータを仲介して収集・取得・蓄積することはありません。

4. 要求する権限（Permissions）の目的

本拡張機能が要求する権限は、主要機能を実現するために必要な最小限のものです。

  • storage: 設定情報や一時コピーデータをローカルに保存するために使用します。
  • host_permissions（各種対象ドメイン）: コピー元サイトからの商品データの読み取り、およびコピー先サイトへの自動入力・画像ロード処理のために使用します。

5. プライバシーポリシーの改定

開発者は、本ポリシーを必要に応じて見直し、改定することがあります。重要な変更がある場合は、本ページまたはストア掲載情報等を通じてお知らせします。

English

SHION INDUSTRIES and Guitar Traders (hereinafter "the Developer") set forth this Privacy Policy regarding the handling of user information in the browser extension "GTcrx" (hereinafter "the Extension").

1. Collection and Management of Personal Data

The Extension does not collect, store, or transmit any user personal or sensitive data (such as login IDs, passwords, names, email addresses, credit card details, etc.) to any external servers, including the Developer's servers.

2. Local Data Storage

Configuration settings (such as the DeepL API key) and temporarily copied product data are saved exclusively within the browser's local storage (chrome.storage.local). This data is managed solely on the user's local device and is never transmitted to or shared with any third parties, including the Developer.

3. Use of Third-Party Services (DeepL API)

When using the translation feature (for listing on Gbase), text data is transmitted directly to DeepL's servers using the API key configured by the user. The Developer does not intercept, collect, or store this data.

4. Purpose of Requested Permissions

The permissions requested by the Extension are the absolute minimum required to perform its core functions.

  • storage: Used to save configuration settings and temporarily copied data locally.
  • host_permissions (target domains): Used to read product information from source sites and automatically populate forms and load images on destination sites.

5. Changes to this Privacy Policy

The Developer may review and update this Privacy Policy as necessary. Any significant changes will be notified on this page or through the store listing information.
